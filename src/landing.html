How it works

Three steps, about ten minutes.

No agents to install and no code changes in your app. Spend Meter reads the billing APIs your providers already have.

Connect your providers

Paste an admin or read-only billing key in Connections. Each one is tested live, then stored encrypted.

It meters every hour

Costs are pulled per model and per service, totalled in US dollars, and charted day by day with a month-end forecast.

You get pinged in time

Set a monthly budget. At 50%, 80% and 100% you get one clear message on the channels you choose.

Questions

Good to know.

Where are my API keys stored?

In your own Cloudflare account, encrypted with AES-GCM. They're only used to read billing data and never appear in the browser. You can also set them as Cloudflare secrets.

Does it slow down or change my app?

No. Spend Meter reads each provider's billing API. It never sits between your app and the provider unless you choose to send gateway logs to it.

Which keys do I need?

An admin key for Anthropic or OpenAI, a read-only Cost Explorer user for AWS, and a Cost Management Reader app for Azure. Google Cloud reports through budget notifications.

How often does it update?

Anthropic and OpenAI hourly, AWS and Azure every six hours, Google Cloud several times a day. You can sync on demand any time.

Can I track APIs that aren't listed?

Yes. Log usage by hand, or post costs from any script or tool to a webhook URL.
